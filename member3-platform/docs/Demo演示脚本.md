# 3-5分钟 Demo 演示脚本

> 演示前准备：MySQL 已导入 `database/rwa_supply_chain.sql`，后端 8080、前端 5173 已启动。
> 种子数据自带：一张已开立凭证（比亚迪 → 科达利 200万）+ 一张待审核发票（聚能永拓 80万）。

## 0:00-0:30 登录与平台总览
打开 http://localhost:5173 ，自动跳转登录页。
点击演示账号标签快速填充，用 `byd / 123456` 登录。
先进入“平台总览”，展示：
- 企业数量 / RWA凭证 / 发票数量 / 融资申请 四个统计卡
- 信用穿透拓扑（数据驱动，随业务实时变化）
- 链节点状态面板（当前为链下存证模式，接入成员1节点后自动切换链上模式）

解说：
“本系统以联盟链为可信底座，将核心企业应收账款资产化，通过RWA凭证实现多级供应商之间的信用穿透，并最终连接银行融资。”

## 0:30-1:20 核心企业：审核发票、开立凭证
进入“核心企业 Portal”。
1. 展示授信额度监控条（开立凭证会实时占用额度）
2. 对待审核发票 INV-2026-0002 点击“通过”
3. 审核通过后点击“开立凭证”——生成新的 RWA 凭证（Token ID / Slot / 到期日）
4. 也可以现场“新建发票”走完整流程

解说：
“核心企业确认真实贸易背景后，将应收账款上链资产化：发票金额映射为凭证 Value，到期日映射为 Slot，并占用核心企业授信额度。”

## 1:20-2:20 供应商：拆分支付、申请融资
退出登录，用 `kdl / 123456`（科达利）登录，进入“供应商 Portal”。
1. 展示持有的 200 万根凭证（未流转）
2. 点击“拆分支付”：选择聚能永拓，拆分 50 万
   —— 页面提示“拆分后子凭证继承原凭证到期日与信用背书，金额守恒”
3. 退出，换 `jnyt / 123456`（聚能永拓）登录：
   可以看到拆分来的 50 万子凭证，来源凭证列显示父凭证号
4. 点击“申请融资”，以子凭证质押向建设银行申请 45 万

解说：
“凭证支持无损拆分：拆分金额加剩余金额恒等于原凭证金额，子凭证继承核心企业的信用背书，信用随拆分向二级、三级供应商下沉。”

## 2:20-3:10 银行：溯源核验、审批放款
退出登录，用 `ccb / 123456` 登录，进入“银行 Portal”。
1. 融资申请列表出现聚能永拓的 45 万申请
2. 点击“溯源核验”：弹窗展示凭证完整流转链
   （比亚迪确权 → 科达利 → 聚能永拓）、底层发票贸易背景、各级 Hash
3. 点击“审批”——凭证进入质押状态
4. 点击“一键放款”——申请完结，凭证进入清算状态

解说：
“银行放款前可一键溯源：凭证从核心企业确权到当前持有人的每一级流转、底层发票、交易哈希全部可查，贸易背景真实性核验从数天缩短到秒级。”

## 3:10-3:50 信用穿透拓扑
回到“平台总览”。
拓扑图已更新为真实业务数据：
比亚迪 → 科达利（200万确权）→ 聚能永拓（50万拆分），建设银行 → 聚能永拓（45万融资）。

解说：
“拓扑图由链上/库内凭证数据实时驱动，核心企业信用沿供应链向多级供应商下沉，实现信用穿透。”

## 3:50-4:30 技术架构说明
展示链节点状态面板与接口说明文档：
- 当前为链下存证模式，业务全流程可演示
- 成员1的 ERC-3525 合约交付后，配置 RPC 与合约地址即可切换链上模式
- 事件监听服务每 10 秒轮询链上事件同步至 MySQL

解说：
“平台采用链上链下协同架构：链上保证资产可信，链下数据库承担查询索引，合约 ABI 确定后无缝切换。”

## 4:30-5:00 总结
“最终形成核心企业、供应商、银行三端协同的 RWA 供应链金融平台。”
